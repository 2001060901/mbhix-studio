# Mbhix Studio — Zwelihle Mbhamali | SEO Specialist

Personal website for Zwelihle Mbhamali, an SEO specialist based in Johannesburg, South Africa, operating as **Mbhix Studio**.

Live pages:
- `index.html` — Home
- `about.html` — About
- `service.html` — Services
- `project.html` — Case studies / portfolio
- `team.html` — Meet Zweli
- `quote.html` — Free SEO quote request
- `contact.html` — Contact details

## Tech

Static HTML/CSS/JS site built on a customized Bootstrap 5 template. No build step required — open `index.html` directly or deploy as-is to any static host (GitHub Pages, Netlify, Vercel, cPanel, etc.).

## SEO

- Unique `<title>` / meta description / keywords per page
- Open Graph + Twitter Card tags
- `sitemap.xml` with priority ranking and `robots.txt`
- Semantic alt text on all images

## Before going live

- [ ] Replace the placeholder domain `https://mbhixstudio.co.za` in every page's `<link rel="canonical">`, Open Graph tags, `sitemap.xml`, and `robots.txt` with the real live domain.
- [ ] Add real Facebook / Twitter / LinkedIn / Instagram profile URLs (currently placeholder `#` links) in `build_site2.py` (`SOCIAL_FACEBOOK`, `SOCIAL_TWITTER`, etc.) and rebuild, or edit the HTML files directly.
- [ ] Swap in real client project photos/results on `project.html` as they become available.
